## 1. Песня: откуда брать

`StartGroup` (= `XX_StartHere.cgr`):

- `CurrentSongTitle` (#3162), `CurrentSongArtist` (#3168) — `[Text]`. Именно их рисует игровой
  `Do_ShowSongName` через `StartGroup::Texter_Unicode`.
  (`cgrpy query writers StartGroup CurrentSongTitle`)
- Пишут их загрузчики песни (`VisMusic` #251/#260/#261 — из имени файла или тегов `"artist  -- -  title"`,
  `CDBrowser` #444/#445 — юникодные, `RadioBrowser`, туториал: `"Tutorial"` / `"Audiosurf"` / `"Team Audiosurf"`),
  заглушка — `"Unknown Artist"` (#252).
- **Игра дописывает в название теги**: `XX_StartHere` #6835…#7147 — `Unicode_Merge(CurrentSongTitle, " [as-steep]")`,
  `" [as-portal]"`; плюс теги, которые пользователь сам вписал в теги файла (`[as-monoonly]` и т. п.,
  `Do_ForceCharacterChanges`). Для показа их надо вырезать: `%s*%[as%-[^%]]*%]`.
- `tw.string_ch` отдаёт UTF-8 (`fam_text.cxx`: спрашивает `GetIfUseWChar`, широкую строку конвертирует
  `WideCharToMultiByte(CP_UTF8)`), так что юникодные названия доходят до Lua целыми.
- **Но не до экрана.** Шрифты оверлея — Roboto Regular/SemiBold (`src/ui/fonts.cxx`), ImGui 1.92 с
  динамической подгрузкой глифов: латиница, кириллица, греческий будут; японского/китайского/корейского в
  Roboto нет — будут пустые прямоугольники. Лечится только в плагине (§7, вопрос 9).

Читать строки не каждый кадр: раз в 30 кадров и на хуках начала заезда (те же, что в `tally.lua`). Результат —
обрезанные теги, измеренные ширины и обрезка с многоточием — кэшируется до смены строки или `font_size()`.

## 2. Миникарта: данные

### 2.1 Как это делает игра

`XX_gui::Do_OverheadMap` #4147 → `Do_RenderTrackSideView` #4808 (`cgrpy query dec XX_gui Do_RenderTrackSideView`):

- `OneTime` → `Do_CreateWhiteTrackTexture` #4844: `CustomTexture` 512×256, пиксель `(col,row)` горит, если
  `row ∈ [MinRenderedPixel[col], +5)` — таблица `Routemap_TrackPixels: MinRenderedPixel` (её заполняет `RouteMap.cgr`).
- Точка игрока `MinimapPlayer` #4857:
  X = `-1 + 2 * Player::OffsetCurrentRing / Highway::NumRings`,
  Y = `(y(Highway::Rings: Pos[RingIndex]) - LowestRingYpos) / (HighestRingYpos - LowestRingYpos)` в пределах `MinMinimapY`.

То есть миникарта — **боковой профиль трассы**: высота кольца по номеру кольца.

### 2.2 Что берём мы

Всё из `Highway` (имена уникальны — `cgrpy query find "^Rings: |NumRings|RingYpos|RingIndex" --group Highway`):

| Канал | Что |
|---|---|
| `NumRings` #65 | число колец (порядка 8 тыс.) |
| `Rings: Pos` #182, курсор `RingIndex` #193 | `tw.array_vec` — y кольца = высота профиля |
| `LowestRingYpos` #469 / `HighestRingYpos` #505 | нормировка по высоте (можно и своим min/max по выборке) |
| `Rings: SongTime` #320 | время кольца — для «осталось m:ss» (опционально) |
| `Player::OffsetCurrentRing` #695 + `OffsetCurrentRingInterpolation` #711 | где игрок, с дробной частью — точка едет плавно |

`RingIndex` — общий скрэтч-курсор семи групп; `array:get` сохраняет и восстанавливает курсор, так что чтение
безопасно.

**Цвета — та же ось, без пересчёта.** `y` строки `StatCollector::Stats: TrafficPattern` — это номер кольца:
`TrafficCommander::Do_BirthCar` пишет `RingToDieAt := y(TrafficPattern)` (#713), и это кольцо, на котором блок
доходит до игрока (`cgrpy query writers TrafficCommander RingToDieAt`). `scan.lua` уже проходит каждую строку
трассы ради знаменателей — раскладка блоков по отрезкам карты достаётся этим же проходом, без единого
дополнительного чтения канала.

### 2.3 Модель

- `BINS` отрезков (≈192) на всю трассу; отрезок `b` — кольца `[b·N/BINS, (b+1)·N/BINS)`.
- **Профиль** — новый модуль `track.lua`: по 2 кольца на отрезок (начало и середина), т. е. ~400 чтений на
  трассу, 128 за кадр — 3–4 кадра. Профиль трассы гладкий (накопленный наклон), читать каждое из 8 тыс. колец
  незачем. Игра сама сэмплирует его в 512 столбцов.
- **Цвета** — в `scan.lua`: рядом с `partial[bucket]` копится `bins[b][bucket]`. 192×6 чисел.
- **Когда пересканировать** — те же события, что для знаменателей (`Do_ResetStats`, `Do_ReseteWhiteWildBlocks`,
  `Do_ResetSimpleStats`): к ним кольца трассы уже построены, потому что строки трафика на них ссылаются. Это надо
  подтвердить пробой (§6, Ф0); запасной путь — пересканировать профиль, если `NumRings` не совпал с тем, по
  которому он снят.

### 2.4 Цвет отрезка

Из счётчиков отрезка — веса цветов, из весов — цвет по **живой палитре** (`COLOURS[i].colour`, её уже держит
`palette.lua`):

1. Сглаживание по соседям (ядро ±3 отрезка): иначе редкие блоки дают рябь.
2. Камень/белый в цвет не идёт (иначе всё сереет); отрезок без цветных блоков — нейтральный (`TEXT`/`DIM`), а
   короткие дыры закрывает сглаживание.
3. Смешение с «заострением»: вес `w^p` (p≈2–3), затем взвешенный `mix`. Чистое среднее в RGB врёт: красный +
   синий дают фиолетовый, а фиолетовый — это самостоятельный цвет блоков. С `p` лидер отрезка забирает цвет, а
   переходы между отрезками остаются плавными.
4. Веса считаются один раз на скан; итоговые цвета — заново при `refresh_palette()` (раз в 30 кадров),
   192 смешения — копейки.

## 3. Миникарта: отрисовка

- Ломаная из `BINS` отрезков, каждый своим цветом, `tw.hud.line`. **Полилинии в API нет** — это ~190 вызовов за
  кадр (оценка +0.05–0.1 мс к нынешним 0.04–0.09) и возможные «швы» на стыках толстых отрезков разного цвета.
  Альтернатива — примитив в плагине (вопрос 4).
- Пройденная часть (левее игрока) — приглушена (альфа ~0.35): это и есть замена заглушенному прогресс-бару
  `Timer2`.
- Точка игрока — `rect` со скруглением в радиус + `glow_rect`, цвет — цвет текущего отрезка.
- Опционально — «осталось 2:31» справа под картой из `Rings: SongTime`.
- Глушим игровую: `tw.mute("XX_gui", "Do_OverheadMap")` (#4147). Довод безопасности уже записан в
  `gameplay-map.md`: узел пишет `Highway::RingIndex`, но каждый читатель ставит его заново сам. В DESIGN.md §3
  добавить строку.
- В туториале (`StartGroup::isTutorial?`) игра карту не рисует — мы тоже.

## 4. Панель «статистика + карта», верх-лево

- Таблица цветов переезжает из низа. Панель фиксированной ширины = ширина таблицы на 6 колонок; при 2–4
  колонках (Mono, Casual, Pro) ячейки растягиваются на всю ширину, чтобы карта под таблицей не скакала по
  ширине от режима. Высота карты ≈ 0.3 ширины.
- **Конфликт:** по умолчанию верх-лево занимает лента уведомлений оверлея (`tw.hud.widget("notefeed")`). Её
  высота меняется с каждым уведомлением — если панель будет её объезжать через `place`, она будет прыгать. См.
  вопрос 5.

## 5. Нижняя полоса и бейдж

### 5.1 Полоса

Сейчас каждый из трёх нижних блоков сам прижимается к `bottom`, и высоты у них разные. Вводится общая полоса
`L.band_y0..L.band_y1` фиксированной высоты, считаемой **от размеров шрифтов, а не от содержимого** — иначе
бейдж прыгал бы на каждое появление Clean Finish. Высота полосы = полный блок цепочки (множитель + таймер +
фичи). Бейдж занимает полосу целиком, содержимое рейтинга центрируется в ней (вопрос 6).

Порядок отрисовки нижних блоков меняется: бейдж → рейтинг → цепочка, потому что цепочка считает своё свободное
место от их краёв (`free_l` сейчас = правый край таблицы, станет — правый край бейджа).

### 5.2 Бейдж

`(T)` — логотип в кружке; название — semibold, крупнее `base`; под ним волосяная линия шириной с название;
исполнитель — regular, `DIM`. Фон — такой же, как у полосы счёта сверху (`surface` × 0.72), со скруглением.

- **Ширина** — по содержимому, но не больше предела, при котором рельсы цепочки на максимуме (бонус 3 →
  `3/16` ширины экрана на рельс) ещё влезают:
  `badge_r ≤ screen_w/2 − (gap_w/2 + rail_gap + 3·screen_w/16 + 24)`. Иначе длинное название укорачивает
  индикатор, который игрок читает по длине.
- Не влезло — многоточие с обрезкой по границе символа UTF-8 (в LuaJIT нет `utf8`, нужен маленький помощник);
  считается один раз на смену строки.
- Пустой исполнитель или `"Unknown Artist"` — строка исполнителя не рисуется, название центрируется по высоте.
- **Логотип.** Скрипт рисует только `icons/*.svg` (монохромные, тонируются); логотип Твикера в плагине есть лишь
  растром — `textures/TweakerIcon-1..7.png`, им пользуется водяной знак (`watermark.cxx`). См. вопрос 3. Пока
  иконки нет, `tw.hud.icon` молча ничего не рисует — кружок остаётся пустым, ошибки нет.

## 7. Изменения в плагине (если решим делать)

Не обязательны для первой версии, каждое — отдельный коммит:

1. `icons/tweaker_logo.svg` — монохромный логотип. API не меняется.

   в режиме `MergeMode`. При динамическом атласе 1.92 платим только за глифы, которые реально нарисованы.

## 9. Вопросы к владельцу

**Нужен ответ:**

1. **Как красить карту** — (а) вдоль линии: каждый отрезок своим цветом, видно, что ждёт впереди; (б) вся карта
   одним цветом, который меняется по ходу заезда по текущему отрезку. Рекомендую (а).
2. **Смешение цветов** — взвешенное с заострением (§2.4) или чистый «победитель отрезка» с перетеканием на
   границах. И подтвердить: камень/белый в цвет не участвует.
3. **Логотип** — (а) монохромный SVG в `icons/`, тонируется как остальные иконки (нужен исходник логотипа в
   SVG); (б) доступ скрипта к цветному растру `TweakerIcon-*` — новое API. Рекомендую (а).
4. **Ломаная** — начать с ~190 вызовов `tw.hud.line` и замерить, или сразу сделать `tw.hud.polyline` с цветом на
   вершину (API 4)?
5. **Верх-лево против ленты уведомлений** — (а) панель стоит в углу всегда, лента рисуется поверх (пользователь
   может унести ленту вправо в настройках оверлея); (б) панель уезжает под ленту плавно, по `roll`; (в) панель
   уезжает в верх-право, если угол занят. Рекомендую (б).
6. **«Выровнять по высоте»** — (а) бейдж и рейтинг занимают ту же полосу, что весь блок цепочки (от верха `x3.2`
   до низа строки фичей); (б) центры бейджа и рейтинга на уровне строки множителя. Рекомендую (а).

**Возьму по умолчанию, если не возразишь:**

7. Фон-панель — у бейджа и у панели «статистика + карта»; цепочка и рейтинг остаются без рамок, как сейчас.
8. Длинное название — многоточие (не бегущая строка); теги `[as-…]` вырезаются полностью.
9. CJK в названиях — запасной шрифт в плагине (§7.3) делаем отдельной задачей позже, не в этой работе.
10. Stealth — цветом `GlobalMonoColor` (цвет дороги в Mono, `StartGroup` #862 — его уже читает `palette.lua`);
    Mono Special — нейтральный `TEXT`.
11. «Осталось m:ss» у карты — да. Вкладку настроек (`tw.ui`, поднимет `@api` скрипта с 1 до 3) — не в этой
    работе.
