# Работа агентов в репозитории

Точка входа — [корневой AGENTS.md](../../AGENTS.md). Этот каталог содержит общие
инструкции разработчика Tweaker, а не поставляемый пользователям AgentKit для
авторов Lua-скриптов. Он не входит в `DevTools/Docs` пользовательского бандла.

| Нужно | Читать |
|---|---|
| Понять три приложения и границы модулей | [architecture.md](architecture.md) |
| Ветки, коммиты, приёмка, отчёт и новые решения | [agent-workflow.md](agent-workflow.md) |
| Сборка, проверки, native-правила, генерация и поставка | [development.md](development.md) |
| Продуктовые ограничения, совместимость, Lua API и UI | [project-principles.md](project-principles.md) |
| CgrPy, IDA MCP, Ghidra и сохранность баз | [reverse-engineering-tools.md](reverse-engineering-tools.md) |
| Руководство нужного модуля или текущая работа | [documentation-map.md](documentation-map.md) |
| Личные пути и локальные инструменты | [шаблон окружения](local-environment.example.md) |

Планы, результаты приёмки и журналы реверса остаются в `Docs/Internal/`.
Нормативные правила записываются здесь; текущее состояние — один раз в документе
конкретной работы. Архивы показывают происхождение решений, а не переопределяют
актуальные инструкции. Неразрешённое новое противоречие записывай с обеими
ссылками и вопросом владельцу; не выбирай версию только по дате файла.

Начни с раздела по своей задаче и следуй адресным ссылкам. Не читай весь архив,
`.cursor` или дампы бесед для восстановления контекста. Вложенные инструкции
применяются только к своей области и не заменяют правила всего репозитория.
